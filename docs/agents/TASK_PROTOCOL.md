# FAMFIN — Task Protocol

## Formato de Tarefa

Toda tarefa deve conter:

```
## Tarefa: [TÍTULO]

### Contexto
- O que motivou esta tarefa

### Requisitos
- O que deve ser implementado

### Restrições
- O que não deve ser alterado

### Critérios de Aceitação
- Como validar que está correto

### Documentação Afetada
- Que docs devem ser atualizados
```

---

## Prioridades

1. **P0** — Bug financeiro (cálculo incorreto, perda de dados)
2. **P1** — Feature blocker (funcionalidade essencial)
3. **P2** — Feature normal
4. **P3** — Melhoria / refactoring
5. **P4** — Nice to have

---

## Checklist de Conclusão

- [ ] Código implementado
- [ ] Testes escritos/atualizados
- [ ] Documentação atualizada
- [ ] HANDOFF atualizado (se necessário)
- [ ] Git commit com mensagem descritiva
- [ ] Output da tarefa informado

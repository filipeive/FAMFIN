# FAMFIN — User Flows

## Fluxos Principais

### 1. Primeiro Acesso
```
Registro → Setup Família → Criar Contas → Definir Categorias → Dashboard
```

### 2. Registrar Despesa
```
Dashboard → Nova Transação → Tipo: Despesa → Categoria → Conta → Valor → Salvar
```

### 3. Registrar Receita
```
Dashboard → Nova Transação → Tipo: Receita → Categoria → Conta → Valor → Aplicar Regras (dízimo, INSS) → Salvar
```

### 4. Transferência entre Contas
```
Dashboard → Transferir → Conta Origem → Conta Destino → Valor → Confirmar
```
> ⚠️ Transferência NÃO é despesa. Não afeta orçamento.

### 5. Definir Orçamento
```
Menu → Orçamento → Mês → Categoria → Definir Limite → Salvar
```

### 6. Criar Meta de Poupança
```
Menu → Poupança → Nova Meta → Nome → Valor Alvo → Prazo → Salvar
```

### 7. Registrar Dívida
```
Menu → Dívidas → Nova Dívida → Credor → Valor → Parcelas → Juros → Salvar
```

### 8. Consultar Relatório
```
Menu → Relatórios → Tipo → Período → Gerar → Visualizar/Exportar
```
